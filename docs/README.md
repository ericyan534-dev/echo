# Echo docs — start here

**Echo is a real-time word-finding co-pilot for aphasia.** It listens to a person
who gets stuck reaching for a word, detects the stall beneath the transcript, and
offers the intended word in ~1–2 s — as an on-screen word card with optional
speech — so they finish their own sentence. HackMIT 2026, Health & Accessibility.

This page routes you to the one or two documents you actually need. The project
overview and quick-start are in the [root README](../README.md); the honest
version history is [`VERSIONS.md`](VERSIONS.md).

## Running it, in one place

```bash
pip install -r requirements-dev.txt
cp .env.example .env                 # put your predictor key in .env
python -m pytest tests               # offline, no key needed (one test needs the PFSD dataset)
uvicorn backend.app:app --port 8000  # open http://localhost:8000 in Chrome
```

The console opens on the **Console** page; **Sessions** and **Settings** are in
the left rail (Alt+1..3). Press *Start listening* and stall
mid-sentence to see the dual-channel timeline; the **Simulate** tab drives the
identical pipeline from typed text when the venue mic is unreliable. Full detail,
model config, and eval reproduction are in the [root README](../README.md).
